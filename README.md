# Anniversary Site 2026

一周年纪念网站

## 设计规范

### 配色
- 背景: `#212121` 深灰
- 卡片背景: `#F2E3CF` 奶油米
- 强调色: `#E35342` 珊瑚红
- 文字: `#F2E3CF` 奶油米

### 字体
- 标题: Caveat + Dancing Script + Gochi Hand
- 正文: Noto Sans SC

### 页面结构
1. Hero - 螺旋笔记本效果，标题逐字动画
2. Timeline - 票据式时间线卡片
3. PhotoWall - 可拖动的拍立得照片墙
4. Footer - "波浪在海面上 萤火在岸边"

### 交互
- 点击页面生成珊瑚红爱心粒子
- 照片可拖动 rearrange

## 运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

静态文件输出到 `dist/` 目录
